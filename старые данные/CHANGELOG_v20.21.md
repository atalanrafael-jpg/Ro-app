# MARSEL V20.21

Дата: 2026-08-12

## Внесено

- Зафиксирован текущий рабочий контур: ремонт ювелирных изделий.
- Явно запрещено активировать производство и продажи без отдельного подтверждения.
- Добавлена политика безопасного изменения данных RO App.
- Зафиксирован обязательный порядок: snapshot → audit → dry-run → approval → minimal write → re-read → post-audit.
- Зафиксировано требование не считать CI success доказательством API connectivity без фактического HTTP evidence.
- Зафиксировано требование не выполнять массовые изменения без проверенного backup/snapshot.

## Безопасность

Изменения не выполняют запись в RO App и не изменяют рабочие данные.
